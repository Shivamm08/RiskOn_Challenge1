How to add a New Instrument BC CH / GG

https://wiki.juliusbaer.com/spaces/fkh/pages/341487826/How+to+add+a+New+Instrument+BC+CH+GG

Add "New Instrument" through Advisory Session 

DESCRIPTION

  •  New Instrument triggers the opening of an instrument at FMA. This is necessary in the session so that the instrument is then also known in the order entry system and in the host.


IMPORTANT

  • For securities with an existing ISIN but not yet available in WeNa, the new instrument functionality should be used.
  • If the order is time critical and the notification is not appearing, we recommend to create a Custom Instrument and execute the order.


OVERVIEW OF THE STEPS

  1. Select a Client and start/open an "Advisory Session" now proceed further with "Add transaction by instrument..."
  2. for our scenario the message will be displayed "No Instruments found"


3. Click on "New Instrument"


4. Enter "ISIN", "Currency", "Price" and click on "Request"


5. Confirmation pop-up message will appear on top right corner which shows that the Instrument opening has been initiated.


6. When the Instrument has been created, a notification will appear. Now you can proceed further within the session. 
    (If the Notification is not been shown after couple of minutes and its getting urgent you have to proceed with the "Custom Instrument Solution")
