Critical monitoring alerts must be resolved within 5 business days. In the past, a qualified contact was required in all cases to inform the client about a monitoring alert. Since November 2025 it is possible to use one-way notification (OWN) to inform the client about (most) portfolio monitoring alerts in an efficient manner, using a pre-defined alert notification document and leveraging the document dispatch process in Wealth Navigator.

Activation of one-way notification (one-time) 

This step is required for existing portfolios in BC CH, GG and MC only.

To enable one-way notification in portfolio configuration (one-time effort) proceed as following:

  1. On next client contact, RM may inform the client about the one-way notification possibility for portfolio monitoring alerts. Channels that can be suggested are e-banking or e-mail.
    Note: Actively bringing up this topic is explicitly allowed. You can contact the client via e-mail or phone or in a meeting, however you must document the agreement of the client.
  2. If the client agrees to receive information about portfolio monitoring alerts for a specific portfolio via e-banking or e-mail, go to the Portfolio Configuration section in Wealth Navigator and in the Distribution tab set One-way notification to enabled.
    This must be done separately for each portfolio (note the service model scope ).
  3. Client will receive a Portfolio Configuration Notification, showing the updated communication channel chosen in writing.
  4. In the last step, a contact note is created for this configuration change. Document the details of the client contact , i.e. the agreement with the client in the comment field.

Note: In general, any portfolio configuration changes should be agreed with the Account Holder or Power of Attorney (or Authorized Signatory in accordance to signatory rights in case of a LE). In case the client does not want to receive monitoring alert information via e-channel, there is the possibility to note this not only in a CCN but also with clicking the respective checkbox in the Portfolio Configuration. 

250

Reasoning behind this activation step:

  • Advisory contracts do not require a qualified contact for the notification of any portfolio monitoring alerts
  • By informing the client about monitoring alerts via a qualified contact in the past, an unwritten contractual obligation was created. The client can expect this established practice to continue. So from a legal perspective, the change to one-way notification, i.e. using a different channel, must be agreed with the client before it can be applied
  • For newly opened portfolios going forward, the one-way notification will be set to "enabled" as a default
  • If the client wants to opt out from the one-way notification in the future, change value back to "disabled" at any time

Justification of monitoring alerts (ongoing)

In the "Portfolio Alerts" overview for any given portfolio, the system indicates which alerts are eligible for resolution via one-way notification. Refer to screenshot below and section  for further details.

The RM or IA selects the alert(s) to be communicated to the client via one-way notification. Several options are available:

  • Select individual alerts to justify (a). To use one-way notification, select only alerts that are eligible for one-way notification and click on "Send one-way" (A) 
  • Click "Send all one-way": Active if all alerts currently open are eligible for one-way notification. They will be grouped and justified together with justification option "client informed" (b).
  • Click "Justify all": Allows justification of all alerts (including non-eligible ones for one-way) using the same justification method—use with care and only when appropriate (c). If any alert that is not eligible for one-way notification is included, the justification option "client informed" will not be available.


 


Step-by-Step Procedure to apply one-way notification

1. Choose justification option: "Client Informed"

This justification option is only available if one-way notification has been enabled for the respective portfolio AND all selected alert(s) are eligible for one-way notification.

Choose the snoozing period: 1/3/6/12 months are available.

2. Document generation

Upon selection, the system automatically generates the Portfolio Monitoring Notification document.

    • The document includes a standardised explanatory paragraph for each selected alert, outlining the current situation and associated risks.
    • The content is pre-defined and cannot be edited.
    • Possible customisations:
      • Language of the document (all official BJB languages are available) - preferred language of the client is preselected
      • Inclusion/exclusion of the portfolio number

3. Define distribution settings

Select the 

    • the delivery channel (i.e. e-mail or ebanking) and
    • the recipient contact(s)

Include a personal message for the e-mail option. The generated notification will be attached automatically.

4. Finalise and dispatch

Click "Submit & Finish" to confirm and dispatch the communication.

5. Documentation

After submission:

    • A contact note is automatically created in the client file. You can complement the comment in the contact note with any additional information (e.g. when you have added additional information) or leave the comment blank respectively leave the pre-defined text that the information was shared. Please note: If you submit the content by e-banking, the channel would be "others". 
    • The dispatched notification document is archived in the system.

Monitoring alerts in scope Monitoringscope

Applicable for BC CH, GG, LU, MC

The following monitoring alerts may be addressed through a one-way notification sent to the client, provided no further discussion is required:

  • Strategic Asset Allocation (SAA)
  • Bond rating below threshold
  • Concentration risk on single positions
  • Issuer concentration
  • Negative view
  • Fair value drop (UK only)


Not Eligible for One-Way Notification – Qualified Client Contact Required

The following alerts require direct engagement with the client through a qualified contact prior to any action. These cannot be resolved via one-way communication due to their strategic relevance:

  • Consolidated Product Risk (CPR)
  • Overall Investment Strategy Check (OIS)
  • ESG Discretionary Mandate Check

These alerts are directly linked to the client’s portfolio investment strategy and Client Investment Profile (CIP). As such, any necessary adjustments must be discussed thoroughly with the client by the RM.

FAQ

💡Who do I send the Portfolio monitoring notification to?

Send the portfolio monitoring notification to the person you would call to discuss the alert with in a qualified contact. This will be the account holder or Power of Attorney in most cases.

💡Can I send the Portfolio monitoring notification and also call my client in addition to discuss an alert?

Communication about a specific monitoring alert in addition to the Portfolio monitoring notification is always possible. This is up to the RM - you know your client's preferences best. Choose the option/combination that fits best, use the alerts as an opportunity to bring up important topics regarding your client's portfolio.

💡Can clients opt-out later?

Yes. Update preference in portfolio configuration at any time. Portfolio configuration notification will be generated and dispatched to the client for any change.

💡Is there a log of who received what?

The alert history shows you how an alert was justified. Documents that were sent to the client are stored in the regular archiving system.

💡Can I use OWN for multiple portfolios at once?

OWN needs to be enabled for each portfolio individually. It cannot be used across multiple portfolios.

💡Does this replace phone calls?

It does. However, you can always call the client to discuss an alert in addition. This is at your discretion to decide.

💡Can I contact any role to discuss the enablement of the one-way-notification?

In general, any portfolio configuration changes should be agreed with the Account Holder or Power of Attorney (or Authorized Signatory in case of a LE). In case the main interaction is with a PoA, it is recommended that the Account Holder / Account Signatory receives a copy of the portfolio configuration change notification. To dispatch the document also to the Account Holder / Account Signatory select additionally "e-mail to me", so you can forward the document also to the additional recipients(s). Please ensure that the submission of the document to the additional recipient(s) is properly documented and archived. 

💡Can any role be chosen to receive the portfolio monitoring notification?

Contacts listed as order givers of a portfolio are on the list of eligible contacts.

💡Why is client confirmation needed in some booking centers before OWN can be enabled?

By using a qualified contact to inform the client about portfolio monitoring alerts in the past, an unwritten contractual obligation was established. In order to change this obligation, the client needs to explicitly agree to switch to one-way notification via e-channel.

💡Does the client have to respond to the portfolio monitoring notification?

No reply is required, unless the client wants to take action. In this case he must proactively contact the RM. This is also mentioned in the portfolio monitoring notification document sent to the client, in the last paragraph.

💡What about collective accounts (multiple Account Holders “and”/ ”collectively 2”)?

Agree the portfolio configuration with all account holders or Power of Attorneys (or for legal entities according to the signatory rights e.g. collective by X) and also forward the portfolio configuration change notification to all account holders or Power of Attorneys (respectively for LE as with required counterparts as per signatory rights): Select one AH as contact to dispatch the document and additionally select "e-mail to me", so you can forward the document also to the additional recipients(s). Same procedure for the Portfolio monitoring notification - must be sent to all account holders or Power of Attorneys or according to signatory rights in case of an LE.

💡How does one-way notification work for consolidated portfolios?

For consolidated portfolios the monitoring of the portfolios happens on the virtual consolidated portfolio (...09.01). The enabling of the one-way notification must also be done on the consolidated portfolio.

💡How can I store the information that the client explicitly declined receiving OWN?

When the OWN preference is set to 'disabled', a checkbox appears to tick 'client contacted and declined'.
