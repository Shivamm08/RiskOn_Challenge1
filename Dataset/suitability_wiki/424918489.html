On top of the above logic, the following exception applies:

  • If a partner is classified as MiFID elective, per se professional or eligible counterparty, the knowledge is set to “good” with all K&E categories except “Digital Assets”
  • If a partner is classified as MiFID elective professional in CoCo bond investments, the knowledge is set to “good” with the K&E categories “non-investment grade Bonds” and “Complex Bonds” (mainly affects RML Spain).

If an account holder has a signed DA-Waiver, the knowledge is also set to “good” for Digital Assets, as the education is part of this process.
