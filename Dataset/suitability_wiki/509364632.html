How can I consolidate portfolios and what impact does it have on the monitoring?


BEFORE YOU START:

Please note that it is only possible to consolidate portfolios if the following applies:

  • same ZR
  • same Service Model
  • same Investment Strategy

Example: You wish to consolidate the portfolios 02.01 and 02.02 of ZR XYZ. Reasons to consolidate are client dependent (sometimes also driven by technical reasons) and consolidation is then appropriate if the client wishes to apply a holistic view over several same Advisory service models having the same investment strategy. Please document the client’s understanding in applying a holistic view in a contact note even though the contact note is not part of the automated process.

Please pay special attention if any portfolio has existing individual configurations and carefully read through the next steps:


OVERVIEW OF THE STEPS

Enter the Portfolio Configuration Screen from the respective portfolio view:

Enter the Consolidation tab where you can select / toggle the portfolio you want to consolidate with the master

Now you can finalize the consolidation by clicking on "Save" and entering the resolution note for it. You will see pop-up message saying that the request was completed:


There is no communication document to the client nor an automated contact note created in the tool, hence please ensure that you have documented the client information in a dedicated contact note (Example: As requested by the client I have opened a second portfolio with the same strategy and agreed with the client to consolidate the portfolios as he still wishes to have a holistic overview over the two Advisory mandates).

The consolidation will happen overnight, i.e. an end of day processing is required.
The name of the new consolidated portfolio will be 09.01 and it is more of a virtual portfolio (this means that it will not be known to any of the order entry tools (such as HOST, OTMS, Toolboxes, Portfolio Analysis, etc.).


Special Case – Portfolio configuration (e.g. SAA, bond rating threshold etc.):

Please note that the consolidated portfolio 09.01 has all thresholds set to default values again.

Case 1: Different portfolio configuration on underlying portfolios:

Example: Client had portfolio 1 with bond rating threshold set to BBB and in portfolio 2 set to B. When consolidating the portfolio, proactively ask the client which rating shall be applied to the consolidated portfolio without advising on the new level/threshold and document accordingly (a notification summarizing the final configuration of the consolidated portfolio will be generated and must be submitted to the client by the RM). Below the example of the respective contact note:

As requested by the client I have opened a second portfolio with the same strategy and agreed with the client to consolidate the portfolios as he still wishes to have a holistic overview over the two Advisory mandates. As the client set the bond rating threshold in the existing portfolio to B, I asked which rating shall be applied going forward without advising on the new level/threshold. Clients replied that they want to apply B also for the new one, respectively on consolidated level. I amended the bond rating threshold on consolidated level and sent them the confirmation by e-mail.

The approach to ask the client about which configuration to apply without suggesting new thresholds applies to existing portfolios that are consolidated but also if a new one is opened and would be consolidated with an existing.

Case 2: Same portfolio configuration on underlying portfolios:

If both underlying portfolios have the same individual portfolio configuration, remember to apply this portfolio configuration also on the new consolidated portfolio. A notification is generated and must be submitted to the client by the RM to activate the change on the consolidated level. Document accordingly:

Client wished to consider all advisory portfolios together, hence I consolidated all portfolios and sent out the configuration notification to inform that previously agreed parameters will also be applied going forward to the consolidated portfolio.


Note: If the client for any reason would like to keep individual parameters on the portfolios, it is not suitable to consolidate, and the portfolios should be kept separately.


PLEASE NOTE FURTHER:

From the next day on, ONLY the CONSOLIDATED portfolio will be MONITORED.
The constituents (i.e. 02.01 and 02.02 in this example) will not trigger alerts any longer.
All relevant alerts will be calculated on the consolidated portfolio.
→ All further action must be performed on the CONSOLIDATED portfolio

In order to use one-way notification on a consolidated portfolio, you must enable it on the consolidated portfolio. 

Placing order using a consolidated portfolio

PLEASE NOTE:

Since Wealth Navigator considers 09.01 portfolios as “virtual”, the real existing portfolios (e.g. 02.01 or 02.02) need to be selected when placing an order only after initiating the Advisory Session at the technical portfolio level (09.01) (see example below).

If your trade starts in OTMS or Toolbox Wealth Navigator will automatically apply the selected portfolio (as mentioned above, they do not know the virtual portfolio 09.01).


OVERVIEW OF THE STEPS

"Start a session" in Wealth Navigator by using the consolidated portfolio 09.01, meaning you select the consolidated portfolio to start the session.



Continue now by adding the Instrument you want to buy and select the real Portfolio from the dropdown for which you want to proceed the trade.

Now continue to complete the session as usual by performing the suitability checks and proceeding the order and finalizing the session with the Contact Note.
