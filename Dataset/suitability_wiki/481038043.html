Process for adding ESG Attributes

https://wiki.juliusbaer.com/spaces/fkh/pages/481038043/Process+for+adding+ESG+Attributes

For OTC Equity Options entered via the User Defined Custom Instrument Interface, the ESG attributes need to be added manually via the available drop down field (applies only to constellations in-scope for ESG, see details here: Client ESG Preferences - Suitability Wiki - Confluence (juliusbaer.com)).

The ESG attributes will be provided by the markets sales desk via an automated e-mail generated out the markets system Space (see example below).



Please make sure to archive this e-mail in OnDemand under the respective ZR.

The ESG attributes from this e-mail must then be added to the Custom Instrument in DiAS.
The attributes to be added depend on the Booking Center:

  • BC CH/GG, RML CH: Only JB ESG Category to be added.
  • BC LU, RML IRL/ESP/LU: JB ESG Category, SFDR proportion* and EU Taxonomy proportions percentage* to be added.


*Please be aware that there are service model limitations for SFDR / EU Taxonomy proportion preferences and that these fields are only enabled for in-scope service models
(i.e. Advisory Advanced)
