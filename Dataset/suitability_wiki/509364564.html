The ESG preference chosen by clients must always be seen both on a ZR/CIP and on a portfolio level. Portfolios can have a higher ESG preference than the one stated by the client in the CIP. The reverse, however, is not possible. If a client does not specify a ESG preference for a portfolio, it will automatically become the same as the preference expressed in the Client Investment Profile. Should a client want to increase the ESG preference (e.g. from traditional to responsible) on a portfolio level, this change can be conducted in DiAS as follows (if there are two or more portfolios under a given ZR):

How is a change done in Wealth Navigator:

1. Enter the Portfolio Configuration Screen from the respective portfolio view:


2. Enter “ESG” and select the respective value – which can only be higher. If you need to amend additional values in other tabs (e.g. SAA Leeway), continue to adjust all values and only then press “save”. Note: It is mandatory to select an account holder or Power of Attorney (PoA) as the order giver, i.e. the change of the ESG preferences on Portfolio level must be agreed upon with an account holder or PoA. The changes will be applied immediately to all places where it is displayed.


3. The distribution screen for the Portfolio configuration notification appears where you can configure, preview, and select the language of the client output.


4. The configuration dialogue allows to amend the language again or hide the portfolio number and previews the document. Press “save & close” to continue with the distribution.


5. Select the contact partner (account holder, Power of Attorney or authorized signatory in case of an LE) and distribution channel to share the document. Note that if the contact partner has e-banking, e-mail to me is not available. It is strongly recommended to use an electronic distribution channel where the archiving of the handover is already stored.



6. Complete the contact note by adding additional information on the client request (see points that need to be documented as well as the example above for guidance). In case you hand over the document directly to the client (using “email to me”) ensure that the handover and evidence is archived. For additional support the changes are already pre-filled.

Note that the changes are only done if you finish the process by pressing “submit & finish”.


Once the preference for the portfolio has been changed, the change will be reflected in the overview in DiAS. The red box shows the new portfolio preference while the green box still shows the CIP client ESG preference
