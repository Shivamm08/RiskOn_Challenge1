3. Structured Products via Derivatives Toolbox (DTB) incl. Spark

DTB is a web-based, real time trading platform developed by JB CH, giving users access to a broad range of products. It allows to customise SP to the client's needs and to simulate various products for different solutions and individual requirements. The DTB includes only JB issued SPs. 

The order process for SPs via DTB is fully automated and ensures a MiFID II compliant process. Order routing: DTB → DiAS → DTB. 

Equity Spark Tool is part of the DTB. This tool enables the user to automatically find best possible investment opportunities based on a defined ballpark. The user can choose from an automatically generated product short list the best matching ideas for the client.
