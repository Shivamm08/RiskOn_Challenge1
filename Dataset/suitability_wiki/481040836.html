ESG check now executed for OTC Equity Options (custom instruments)

https://wiki.juliusbaer.com/spaces/fkh/pages/481040836/ESG+check+now+executed+for+OTC+Equity+Options+custom+instruments


Booking Center: CH / GG / LU
Advisory Locations:  CH, LU, ES, IE
Client Domicile: All
Services Models: Advice Light, Advice Premium, Advice Exclusive, Execution Only, PSR


The user defined custom instrument interface has been enhanced to allow the manual addition of ESG attributes in DiAS for OTC Equity Options received from Markets.


In order to enable ESG suitability checks for the above mentioned workflow, you can now manually add the ESG attributes received from Markets to the user defined Custom Instrument interface.

This means the following manual drop downs have been added:

BC CH version of ESG-enhanced User Defined Custom Instrument Interface

ESG Category (relevant for BC CH, GG & LU) with possible values:

  • Traditional Investment
  •  Responsible Investment
  • Sustainable Investment
  • ESG Risks
  • No Data

BC LU version of ESG-enhanced User Defined Custom Instrument Interface

SFDR Proportion (only for BC LU) with possible values:

  • Yes (100%)
  • No (0%)
  • No Data

EU Taxonomy Proportion (only for BC LU) with possible values:

  • Free text field where values from 0%-100% can be entered.
  • Tick box “No Data”

The ESG suitability checks in DiAS and their alert handling remains unchanged.
