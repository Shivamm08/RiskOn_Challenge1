2. Description of the alert

The JB Strategic Fund Access Mandate limits the number of funds allowed per portfolio. This differs depending on the Advisory Locations (3 for CH, 1 for UK). The alert checks that the number of investments adheres to this limit.

Please Note: Several funds with the same Fund ID count as 1 position.


3. What triggers this alert?

A Restricted Portfolio Position alert can be triggered either:

a) in the Advisory Session as a result of a new transaction exceeding the defined limit of fund positions, or

b) in the Client Book as a result of an overnight portfolio risk monitoring if the portfolio has more than the defined positions
