Custom instrument should only be used in cases where the instrument can not be found in WN or Toolbox and the creation of  New Instrument doesn't provide a solution within 5 minutes. 

In most cases the custom instrument mask is self-explanatory, however for certain FX toolbox products additional examples are provided below: 

FX Derivatives - Plain Vanilla FX Option

  1. Select Product Type and Sub-Type
  2. Capture an instrument name. As there is no field to capture the strike price, it is recommended to enter it in the name as this is then also visible in any PIR
  3. Capture the maturity date (expiry date) and option type
  4. Note: Asset Class and PRR are fixed for custom instruments and can not be amended
  5. In the price field the premium shall be captured
  6. Add any pricing details to ensure the cost disclosure
  7. Finalize rest of the fields including type (buy/sell open or close), units and solicitation type and press "add"
  8. The manually captured custom instrument is then visible in session for required suitability checks, while the execution remains outside WN → e.g. order placed after Session via the trading desk. 

FX Derivatives - Forward

  1. Select Product Type and Sub-Type
  2. Capture an instrument name
  3. Capture the maturity date and the forward rate
  4. Note: Asset Class and PRR are fixed for custom instruments and can not be amended
  5. In the price field the forward amount needs to be captured
  6. Add any pricing details to ensure the cost disclosure
  7. Finalize rest of the fields including type (buy/sell) and solicitation type and press "add"
  8. The manually captured custom instrument is then visible in session for required suitability checks, while the execution remains outside WN → e.g. order placed after Session via the trading desk. 

Note: In case of a FX Swap you will find a "maturity date" field (for near date) and a "far maturity date" for the far date. Additionally, it needs to be paid attention to select the correct type (e.g. Buy represents Buy/Sell combination). 

Generally, if any information can not be captured in dedicated fields it is recommended to note them in the name. For Accu/Decu/TARF this could be e.g. the number of fixings, amount per fixing, leverage, strike or knock-out.
