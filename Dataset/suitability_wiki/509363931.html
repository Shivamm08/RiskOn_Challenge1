Overview

Each advisory service model contract has a defined investment strategy and a set of investment guidelines (portfolio configuration). These portfolio configuration parameters set the boundaries for subsequent advisory activities with the client and define the monitoring thresholds (where applicable):

  • JB Advice Light/Basic: Only when providing advice (upon request) or entering unsolicited orders (alerts are triggered in the Advisory Session only)
  • JB Advice Premium/Exclusive/Advanced (and IA direct/indirect): When providing advice or entering unsolicited orders (i.e. alerts are triggered in the Advisory Session) and overnight monitoring

In certain cases, it is permitted to amend the portfolio configuration for the above-mentioned service models upon request and mutual agreement with the client. 


Portfolio configuration topics:

  • Mandate:
    • Minimum bond rating threshold
    • Issuer concentration risk threshold
    • Fund splitting analysis
  • SAA Leeway: Strategic Asset Allocation (SAA)
  • ESG Preferences
  • Loan configuration
  • Portfolio consolidation
  • One-way notification for portfolio monitoring alerts


For all cases the following guiding principles need to be adhered to:

DOs

DON’Ts

Before adjusting portfolio configuration, ensure that the client investor profile is up to date and the client still has the same investment objectives and risk ability and therefore also the right investment strategy.

Don’t actively suggest performing portfolio configuration changes without prior request from the client. There must be a specific need expressed by the client that is covered with the adjustment. Trigger points to discuss such a need for adjustment of the configuration can be a new monitoring alert (it is permitted to explain the banks methodology, it is however the client who needs to raise a question or express a need - e.g., wishing to reduce or disable alerts, or seeking advice outside the SAA). However, don't propose the level of the adjusted threshold but let the client decide based on the specific need. Pay special attention to country guidelines and clients classified according to MiFID to not breach any reverse solicitation rules. Detailed guideline on reverse solicitation application can be found here.

Exceptions to this reverse solicitation (request from the client) principle apply only to Fund-splitting, Lombard Loan configuration, One-way-notification changes, and Portfolio consolidation, where an active conversation is permitted as they do not consist of a change in the service/product but rather a change of visualization and level of monitoring within the same service/product. Fund-splitting even may be activated on discretion of the RM (please see separate chapter linked above). 

It is permitted to factually inform the client about the bank’s portfolio monitoring and advisory thresholds. In case the client wishes to amend the portfolio configuration (on his/her own request) and a change is permitted, follow the detailed "how to amend"-guideline and ensure that the conversation is duly documented, including the client request for any change (where applicable)

Don’t forget to document the agreement with the client in a contact note, which should provide detailed circumstances to evidence the clients’ own request/discussion à see further details and contact note examples in the specific “how to amend”-pages.

If the client investor profile is outdated or the client seeks to amend the investment strategy, assess the changes, and initiate the required changes (there might be a mandate contract change needed as well). 

Don’t simply adjust the portfolio configuration instead of updating the investment strategy where the latter would be appropriate. The portfolio configuration should not be seen to accommodate any ad-hoc client preference or temporary deviations which are not sufficiently reflected in any strategy.

Check any advice/order execution in WN first and respect the applicable boundaries and thresholds. Do not provide active advice that leads to breaches, e.g., in bond-rating threshold, CPR and/or SAA.

Don’t amend the portfolio configuration to excessive thresholds just to avoid any alerts (e.g., SAA changes to 0-100% for all asset classes or Issuer Concentration to 80%). The thresholds are set by default to reflect the bank’s advisory standard.

Address overnight alerts and inform the client about deviations by recommending appropriate measures to bring the portfolio back to the agreed parameters (increasing/ decreasing exposure by buying/selling positions).

If the client accepts a temporary deviation, document this risk acceptance (“client accepts risk”) accordingly.

Don’t amend the portfolio configuration without a client contact /instruction.

Important to note:

  • In general, any portfolio configuration changes must be agreed with the Account Holder or Power of Attorney (or Authorized Signatory in case of a Legal Entity).
  • Any change that is done on the portfolio configuration for above mentioned service models (except portfolio consolidation) will produce a client notification in WN and must be shared with the client  or Power of Attorney via e-channel.
  • This notification does not replace the duty to duly document the request, agreement and background details. Further details can be found in the single process descriptions (“how to amend…”).

The current portfolio configuration is visible in any PIR / PAR document irrespective of whether adjustments have been made. This adds transparency for the client regarding the values on which we advise and monitor the respective portfolio.
