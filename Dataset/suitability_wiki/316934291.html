2. Description of the alert

The Share Class Selection Logic (SCSL)-alert ensures that a client is offered the most appropriate share class of a third-party or JB investment fund. Essentially, it checks if there is a less expensive share class available with the same characteristics and currency and which meets the client's context. Same characteristics include currency, hedging and distribution type (accumulation/distribution) but e.g. not any distribution frequency. More details on the comparison see →Share Class Selection Logic (SCSL)


3. What triggers this alert?

The alert is triggered in the Advisory Session when a more appropriate share class is available. 


4. How can this alert be resolved?

You can resolve the alert with one of the following actions:

Advisory Session (session alert)

Duty

RM/IA must not proceed with the transaction because the investment advice is unsuitable

If the client accepts the proposed share class:

RM/A to "accept appropriate share class" in Wealth Navigator. The share class will replace the "old" share class in the session.


Reverse solicited

RM/IA must inform the client that there is a more appropriate share class available and advice against the less appropriate share class

If client accepts the less appropriate share class:

RM/IA to select “client confirms” in the alert justification. As rationale the RM must select one of the following dropdowns:

- Client preference (distribution): if client still wants to buy this one because of distribution consideration

- Client preference (tax): if the client still wants to buy this one because of tax consideration

- other: if the still wants to buy this one because of other considerations (pls. add rational of the client to the comment)


Unsolicited

RM/IA must warn the order giver before executing the transaction

5. Process when client already has an existing holding (top-up)

SCSL does not consider existing holdings in the client portfolio. However, a toping up an existing holding might allow the client to invest into a more appropriate share class that has a higher minimum investment threshold. The combination of the existing holding and additional investment could meet the required minimum investment amount.

  1. RM/IA should manually check the client’s portfolio to determine whether an existing holding already exists and if the client would meet the minimum investment amount of another share class.
  2. If yes, RM/IA should assess, if the switch of the existing holding into the more appropriate share class makes economic sense. Switching makes economic sense if re-allocation costs are smaller than the potential cost savings.
  3. If yes, RM/IA should contact Mutual Funds Dealing ( mutualfundsdealing@juliusbaer.com ) to understand and receive the cost implications. The Tax Competence Centre will be involved. The RM/IA receives an answer on switch possibilities and related costs. Potential tax implications will be highlighted. Note: When switching into retro-free share classes, usually no re-allocation costs occur and no tax implications prevail. However, this assessment will be done for you by the Tax Competence Centre.
  4. If the reallocation makes economic sense, RM/IA should advise the client to re-allocate the holdings into the more appropriate share class.
  5. If the client agrees to the proposal, RM/IA should initiate the switch via Mutual Funds Dealing. Do not initiate the switch in Wealth Navigator.
  6. RM/IA duly document the decision and discussion with the client.
