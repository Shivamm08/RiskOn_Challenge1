Custom Instrument Solution (in Session)

https://wiki.juliusbaer.com/spaces/fkh/pages/394301255/Custom+Instrument+Solution+in+Session

IMPORTANT:

  • If an instrument cannot be found in WeNa and the creation of New Instrument doesn't provide a solution within 5 minutes, then we recommend to use the custom instrument solution.

DESCRIPTION

  • Custom Instrument is a construct in WeNa where the RM can set up an instrument himself and the scope is only WeNa. If the instrument is passed on to the Order Entry,
    it has a 666666 Valor.
  • Custom Instrument can be used if a newly opened instrument in FMA is not delivered by FMA because the Instrument Data Provider does not have the instrument.

When the RM places an Equity/FX derivative trade via the trading desk, a pre-trade WeNa session is required.

In this case the custom instrument solution for the pre-trade WeNa session must be used.

Only if the WeNa session, i.e. suitability assessment is positive, the trade can be placed.

Within Custom Instruments WeNa Session it is required to indicate the costs by entering either the absolute amount in instrument currency or in % of the nominal amount. Based on this input the system is calculating the upfront charge and discloses the cost for a custom instrument in the pre-trade disclosure document.

Please note: Not every instrument is available as custom instrument. There are two possible solutions: a) Use the custom instrument available in the Proposal (there is a wide range of products available, see separate wiki page) and then import the proposal into the Wealth Navigator Session for the pre-trade checks or b) select the most suitable instrument having the respective parameters incl. PRR available to simulate the pre-trade suitability (add missing information into the description of the instrument). 

Steps how to Add Custom Instrument:

To create a 'Custom Instrument' since the one which you want to use is not available and/or not yet opened, you click on the search bar and select the option for 'Custom Instrument'.

Now within the 'Product Type' Dropdown you can select the corresponding product and product sub-type:


Once the Product and Product Sub-type is selected, fill out all mandatory fields for your instrument. This allows the completion of the suitability checks and ensures that the user can proceed with completion of the session.

If an instrument is already available and does not require a custom instrument, the RM will be informed as shown in the screenshot below. 
In this case it is recommended to enter the already existing instrument directly in the search bar.

Alert Handling

Guiding Principles:

  • Session alerts need to be communicated to the client before you proceed with placing the orders
  • Active advice must never result in any suitability or cross-border breach. Do not proceed but amend your proposal in order to resolve the alert

Mandatory Document Disclosure Alert ("MDDA")

  • No KID - no trade principle is also applicable for custom instruments (regardless of the client classification).
  • KID (prospectus for Hedge Funds) must be uploaded manually. If no KID/prospectus can be found, trade cannot be executed! Don't justify the alert with "document already provided", if no KID/prospectus is available
  • For unsolicited orders, ask the client to provide you with the document and upload the document to WeNa. 

Distribution Rules:

  • For NTFs, product distribution rules must be checked manually.

Solicitation Alert

  • Will always pop-up as custom instrument is unknown (for solicited or reverse-solicited transactions)
  • Advice on instrument outside of the offered universe is not permitted. Do not oversteer the alerts, but inform the client, that you cannot advice on this instrument and change to the solicitation type to "unsolicited". 

If the custom instrument is part of the offered universe, please use justification "checked manually". → Please ensure to attach evidence (e.g. email from the markets with the universe status of the instrument) to the contact note at the end of the session.

ESG

For details on regarding the process for ESG attributes (relevant for ESG in-scope locations and OTC Equity Options), please refer to this: link 

Configuration

  • Only Asset-Class-based and Portfolio-based alerts are triggered for custom instruments
  • The highest Product Risk Rating ("PRR") of the respective asset class is allocated to the custom instrument
  • No Manufacturer Target Market ("MTM") data is retrieved. Therefore only the Distributor Target Market ("DTM") is checked

Order Processing

At the order entry step the following possibilities for processing orders are available:

  • Fixed Income, Equity and Hedge fund custom instruments can be processed via the order entry system
  • Private equity cannot be processed via any order entry system. Further info can be found here: Link
  • Hedge Funds cannot be processed via any order entry system. Further info can be found here: Link
  • FX Derivative and Equity Derivative cannot be processed to any order entry system. The RM must call the Trading desk to execute these orders

To complete the WeNa session please move on to the contact note step and fill in the necessary information.
