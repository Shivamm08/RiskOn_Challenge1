Client Reporting on Proposal Level

Client Package you may choose between the:
- basic Proposal Summary or the
- detailed Personal Investment Recommendation

Proposal Tool: Configuration of Client Package for a “Proposal Summary”

1. Proposal Summary: The language can be changed if required (default language is set according to CRM)

The report can be inspected either in the preview (shown on the right hand side) or by downloading it as a pdf (using the arrow showing downwards)

2. Page Configuration: The portfolio number can either be changed manually (by overwriting the default) or made invisible by ticking the box “Hide Portfolio Number” (in case it shall not be disclosed)

3. Additional Documents: The documents you have added to your Proposal Summary can be previewed, downloaded as pdf  or changed in terms of sequence by using the respective icon.

4. Manage Documents: This button provides you a separate configurator window in which you can:

4a. Upload additional Documents which you wish to share with your client
4b. Add Research Material (e.g. JB House View)
4c. Add Marketing Material (e.g. the so called Portraits from PSP)
4d. Manage the Disclosure Documents

5. Use standard paging and zooming functionality

6. Clicking on NEXT brings you to the Sharing Configuration where you can select your contact partner and the distribution channel as you know from the DiAS session.

6a. Select the Contact Partner as well as the Channel you wish to use for the delivery of the client package. For E-mail distribution a copy to yourself can be selected.
6b. If you select E-Mail as distribution channel you can further tailor your proposal through a personal mail
6c. The E-mail preview is shown on the right hand side
6d. An e-mail preview can be sent without closing the configuration window in order to do additional changes

7. If you like to change your client package you can always go back by clicking on the “Change Client Package” button.
In case you are fine you can proceed by clicking on the “Send” button or you can close the configurator and further engage in your client package at a later stage.

Proposal tool: Configuration of Client Package for a “Personal Investment Recommendation”

The Personal Investment Recommendation (PIR) contains all elements of the Proposal Summary (PS) as described above. In addition, the PIR contains the following possibilities to configure your personal proposal:

  • Highly configurable report and client packages
  • Bullet Point List and Free Text for further tailoring of the report towards dedicated client needs
  • Drill down views on Asset Classes can be added
  • Sell and buy recommendations list to be selected
  • Portfolio Health details can be added

All the other parts of the client package configurator are very similar to the one of the Proposal Summary as explained above.

1. Highly configurable report and client packages

1.1. Configure your cover page

1.2. Adding or removing entire reporting sections such as Portfolio Overview, Asset Class drilldowns, Buy and Sell Recommendations, Suitability Assessment or selected details and graphs for all the reporting sections

1.3. Changing the sequence of the pages / sections by using the drag and drop symbol

2. Bullet point list and free text for further tailoring the report

Which output to use for portfolios with hedging

In case the portfolio is hedged the Consolidated Product Risk, Over/Underexposure and Concentration Risk are not taking into account the change in risk reduction, hence a Personal Investment Recommendation (PIR) should be ordered/created instead of the Proposal Summary (PS).
