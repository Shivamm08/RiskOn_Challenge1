How to place an order for FX Forward Limit Order through DiAS

DESCRIPTION

  • This description provides guidelines on how to handle an FX Forward Limit Order in DiAS
  • Only FX Forward Limit Order have to go through DiAS. FX Spot Limit Order are out of scope of DiAS.
  • Limit Order Section in FX Toolbox is not connected to DiAS, hence before placing the order, a DiAS Advisory Session has to be performed prior to placing the order for all limited FX forward orders.


OVERVIEW OF THE STEPS

  1. Create the Limited FX Forward in DiAS by creating custom instrument ( Steps 1.1-1.4)

  2. Perform Advisory Session in DiAS with the created Limited FX Forward Product
  3. Enter the Limited FX Forward order in FX Toolbox

How to place an order for FX Forward FX Limit Order: Create Custom Instrument ( similar to 7*6 in HOST)


1.1 Create the Limited FX Forward in DiAS by creating custom instrument. In the "Proposal" Screen user goes through "Positions" to the option "ADD POSITION" then selects from the Dropdown "ADD CUSTOM INSTRUMENT"


1.2 Add the requested instrument and follow the steps


1.3 Fill in all details: 

  • Risk Rating: always high for FX forward transactions
  • Price: enter the required limit for the forward order
  • Name of the instrument on line 1
  • Click on NEXT


1.4 Now click again on NEXT to save the custom instrument


1.5 Within the Position tab you can proceed now by adding the created custom instrument by searching via Identification number (marked in the screenshot above)



1.6 In order to proceed further with the Order with the newly created instrument the switch to the Proposal Details Tab needs to be done and within the 'Status' → 'Visible in Session' checkbox ticked which would make this created proposal visible in the session and click on top on Advisory session

How to place an order for FX Forward FX Limit Order: Add Custom Instrument in Advisory Session (similar to 7*6 in HOST)


2. 1 When the session is initiated, select within the communication form the order giver and communication channel and follow the next steps

2. 2 Now we should select the left navigation in order to see the proposal which we have created which includes our created new instrument,
which we can easily load into the Transactions basket by hitting '+' 


 2. 3 Due to the fact that session is not automatically connected to the LIMIT ORDER section of FX Toolbox the step of "PROCESS ORDER" can be skipped and FX Toolbox can be opened to place the limit order.

How to place an order for FX Forward FX Limit Order: Place the limit order in the order entry tool (FX Toolbox)


 3. 1 Open the order entry tool (FX Toolbox) and fill in the relevant entries within "Product Data"
 3. 2 Add the Client and the Amount, the "ACCEPT" Button should become active which now can be selected. 


 3. 3 Place the limit order and create Contact note to finish the Session
