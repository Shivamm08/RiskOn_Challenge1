How to amend the Fund Splitting Analysis

https://wiki.juliusbaer.com/spaces/fkh/pages/509364445/How+to+amend+the+Fund+Splitting+Analysis

By default, WN has disabled the fund splitting analysis as today we do not always have look through data available (e.g., for funds). The benefit of having fund splitting available is that there is additional transparency on the asset allocation – provided the data is available. This possibility can be actively discussed with the client and if wished by the client also activated , however, the limitation that we depend on data availability to unbundle instruments may be mentioned.

In case the RM enables the fund splitting without prior discussion with the client (which is specifically permitted for the fund splitting option), RM shall ensure sending out the system-embedded change notification accordingly via e-mail or e-banking.

Example contact note:        

Client decides to invest an amount in a JB Strategy Fund for a Balanced Strategy in CHF. In WN the RM sees a Strategic Asset Allocation Exposure alert mentioning that the Alternative investment & others threshold (0-25%) is breached (currently 37%). Client does not have any alternative investments in the portfolio. I explain to the client that Funds investing in different asset classes are considered as Alternative investments & others in our monitoring. I inform him that we have a fund splitting possibility whenever the data is available, which for this instrument would be applicable to have a better overview - client agrees to activate. 

Example contact note without prior discussion:

I activated fund splitting in the portfolio as the client has several JB funds to permit a more accurate Asset Allocation display without prior discussion with the client. Portfolio Configuration Change Notification submitted via e-banking.


How is a change done in WN:

1. Enter the Portfolio Configuration Screen from the respective portfolio view:


2. Enter “Mandate” and adjust to the desired monitoring value for the Fund splitting analysis. If you need to amend additional values in other tabs (e.g. SAA Leeway), continue to adjust all values and only then press “save”.

3. The distribution screen for the Portfolio configuration notification appears where you can configure, preview, and select the language of the client output.

4. The configuration dialogue allows to amend the language again or hide the portfolio number and previews the document. Press “save & close” to continue with the distribution. Note, Fund Splitting is only mentioned in the overview table when enabled, if disabled, the document will not show the value anymore, indicating to the client, that this is no longer belonging to the configuration.

5. Select the contact partner and distribution channel to share the document. Note that if the contact partner has e-banking, e-mail to me is not available. It is strongly recommended to use an electronic distribution channel where the archiving of the handover is already stored.

6. Complete the contact note by adding additional information on the client request (see points that need to be documented as well as the example above for guidance). In case you hand over the document directly to the client (using “email to me”) ensure that the handover and evidence is archived. For additional support the changes are already pre-filled.

Note that the changes are only done if you finish the process by pressing “submit & finish”.

Important Note:

If fund splitting is activated, funds having fund splitting data available will be split into their individual JB asset class level 1 components. Asset allocation-based checks (i.e. SAA and TAA) will respect the settings made on portfolio level. By default, fund splitting is not activated. Enabling fund splitting comes with the benefit of having increased transparency especially for multi asset class funds (e.g. strategy funds). However, it also comes at the price that you then have to deal with this additional transparency (e.g. you will also get leverage data from derivative overlays and the like).
