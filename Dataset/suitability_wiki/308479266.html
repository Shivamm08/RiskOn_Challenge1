Background and products in and out of scope

In order to comply with the suitability and MiFID II requirements, any instrument type falling under these requirements, has to be processed through an advisory session, before the order can be sent to the
respective market.

The following instrument types have to be processed through an advisory session, before they can be placed via OTMS:
-Exchange Traded Derivatives (ETDs)
-Primary Market:
 o Structured Products in subscription
 o New Issue Bonds in subscription (NIB)
 o IPOs

Note: Lead orders have to be opened via Markets (phone call). Once the product is created, an advisory session via OTMS is required.

OTMS related transactions out of scope of an advisory session are:

  • Payments
  • Money Market (Fiduciary)
  • Nostro
  • Loans

Any order entry tool will always prompt you to session, if the instrument type falls under the suitability and MiFID II requirements.

Step-by-step order entry

1. Initiate the order in OTMS under the respective portfolio. If an advisory session is required for the chosen transaction, a respective warning is displayed in OTMS.
2. Click on ‘Yes’ to proceed. You will be automatically prompted to session.

3. You will be automatically prompted to session with the pre-filled information about the instrument. Note: You can only modify the transaction type (e.g. subscription) and the unit in OTMS and not in DiAS.

4. Click on ‘Process’. Note: For OTMS related transactions, the ‘Process All Orders’ is not working (technical limitation). You have to process each order individually.


5. Depending on the instrument you are trading, you have to proceed as follows:

  • Structured Products, IPO and New Issue Bonds: orders are processed automatically.
  • ETD orders need to be verified in OTMS again due to the time lag and potential price movements(see screenshot below).

6. Once the ETD order has successfully been sent, a respective notification pops up.

Error message in OTMS

In case you are initiating a trade for a portfolio for which an advisory session is still open, OTMS displays a respective error message in the ‘Message Ticker’ field: ‘reject of IAP (=WN) order request’.

In this case, you first have to finish the open session in WN. After that, you can return to OTMS and double click on the error message to re-submit the order. You will then be prompted to a new advisory session.

Block orders

Block orders can be initiated out of OTMS, but you need to complete for each portfolio a separate advisory session in WN.
