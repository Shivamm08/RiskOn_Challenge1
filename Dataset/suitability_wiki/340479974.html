How to place block orders under WN for: Multiple Clients to trade the same instrument


OVERVIEW OF THE STEPS

  1. Follow the WN process until to the step order entry
  2. Click on the  ‘four squares’ next to Process to add to ‘block order’
  3. Afterwards start again a session for another client and follow steps 1-3 again until all clients have been added to the block orders.


5. Click on the List next to the ZR search field
6. The Block Orders list is been displayed and "process all orders" now

7. Now once you are re-directed to Portfolio Analysis proceed with "update all orders" there and complete the execution.

How to place Block Orders under WN for: FX & FX Option Products


DESCRIPTION

  • As the FX Toolbox and the FX Option Toolbox do not offer the functionality to process block orders in the context of WN (similar to Portfolio Analysis) there is a workaround in place
  • FX block orders can be placed via phone with FX PB Solutions: # 88484
  • But before placing the order, a WN Session has to be performed on every affected portfolio (Pre Order Checks)
  • Pricing and execution is done by FX PB Solutions


OVERVIEW OF THE STEPS

 1. Create the product in FX or FX Option Toolbox
 2. Select  / Add "Currency Pair, Value Date, Client & Amount"
 3. Proceed by click on "PROPOSE"

Note: The orange notification shows when an order needs to be processed via WN. In this case (and only), the standard button (“ACCEPT”) will be converted into “PROPOSE”.


  5. WN Session will be automatically started for the first client in a new Tab.
  6. Perform all steps until ‘Order Entry’
  7. Skip the  ‘Process’  step in WN
  8. Create the Contact Note & Finish the Session
  9. Go back to Toolbox, choose the next client apply the same FX rate and trigger the next session with ‘Propose’
10. Call FX PB Solutions for execution of the block order
11. FX PB Solutions will directly execute the trade on ZR/portfolio level – there is no further action required from the RM
12. Trades will be flagged as STP and STP COPS will be charged




How to place block orders for DTP Products

Trade the same Derivate Toolbox Product for 2 or more portfolios

DESCRIPTION

  • As the Derivative Toolbox does not offer the functionality to process block orders in the context of WN (similar to Portfolio Analysis) there is a workaround in place
  • If the total ticket size is >500k CHF, Structured Products Advisory will open a product in OTMS (no minimum ticket size is required for FX Reverse Convertibles). For smaller ticket sizes block orders are not offered.
  • Once the product is a available in OTMS, the standard OTMS/WN process applies


OVERVIEW OF THE STEPS

  • Call Structured Products Advisory to set up the respective product in OTMS:
    ** For products with FX underlying's:   # 88484
    ** For or all other products:   # 88181
  • Subscribe to the product in OTMS per client
  • Perform Advisory Session in WN for each portfolio
  • Complete subscription in OTMS (choose transaction type “subscription” in DiAS)
