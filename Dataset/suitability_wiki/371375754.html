In order to make documenting in Wealth Navigator/DiAS as efficient and accurate as possible, please keep in mind the below basic points:

How to document

Write in good quality and in a way that any other person would understand what has been done and agreed. State clearly for which instruments you have provided advice and which transactions were executed without advice and archive any corresponding documents (e.g. e-mails) properly. 

 

Remember -anything that is documented can be requested/shown to the client, or to their legal representative. Incomplete documentation may expose the Bank to litigation and / or problems with the regulator.

Use the right solicitation type

It is not only sufficient to chose the correct solicitation type, you also must write down:

a) who came up with the investment idea

b) How the decision was made to trade the specific financial instrument

c) for each financial instrument, whether advice was provided or not.
Note: In case the Session contains several financial instruments with different solicitation types, add this information to each instrument, allowing to understand whether advice was provided or not

Use the right justification type

You often have a choice between several justification types. Make sure the one you use makes sense.

 

“Data Exception” (= Wealth Navigator/DiAS data is wrong) cannot be “client request”, “client accepts”, “OK”, etc.

What needs to be included

Especially in the case of "client accepts risk", the following 3 elements (cumulative) must be discussed with the client & accordingly documented:

  • Which risks where communicated to the client & was advice provided (what suggestion was made)
  • Client’s decision (to hold, to reduce or to sell the position)
  • Client’s rationale & motivation

Referring to existing documentation

If you refer to an existing contact note / resolution note, include the date when that note was created.


When referring to documentation outside of Wealth Navigator/DiAS (e.g. in CRM) this is crucial for finding the information.

No need to repeat yourself

Anything that has been documented in the advisory session does not need to be repeated in the contact note.

Also make sure when you have e.g. an e-mail and call back the client, that you document in a comprehensive way: E.g. if you choose "E-mail" as channel, mention in the free text that you called the client afterwards. 

But ensure that everything documented prior to the contact note is accurate and of good quality.
