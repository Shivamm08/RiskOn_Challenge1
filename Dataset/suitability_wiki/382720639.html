Advisory Equity List

https://wiki.juliusbaer.com/spaces/fkh/pages/382720639/Advisory+Equity+List

In order to help the Relationship Manager to invest larger cash amounts into the portfolio they can add Advisory Equity Lists.


1) From the Portfolio page select 'Proposals' this will bring you to the overview page where you can find all your proposals made for this specific client or start a new one.


2) Select 'Create new' unless you have already an saved proposal from the list.


3a) On the right hand side, select 'Blocks' to see the available Building Blocks.


4a) Open the drop down menu next to Advisory Equity List.


5a) The Advisory Equity List is structured into building blocks. The blocks are pre-filtered along 3 dimensions to condense the view to only show the most relevant equities for this specific region.


6) If the user wishes to add an entire block, use the ‘Add All’ button. To add individual instruments, use the ‘+’
item on the right side. 


7) The blocks or individual positions will be added to the proposal.
