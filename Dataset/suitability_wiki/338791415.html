1. For which Service Models is this alert triggered?

Please find all information in the following chapter: →Alerts configuration per Advisory Location


2. Description of the alert

The investment universe for "JB Strategic Fund Access" mandates is restricted to in-house funds (i.e. "JB Funds"). The check is active for all buy-like transactions and validates whether the selected fund is a JB Fund. You can also find all JB Funds in the →Fund Gallery. 


3. What triggers this alert?

A Restricted Instrument Offering alert can be triggered either:

a) in the Advisory Session as a result of a newly proposed buy-like transaction in a fund other than a JB Fund 

b) in the Client Book as a result of an overnight portfolio risk monitoring when a portfolio with the „JB Strategic Fund Access“ mandate has positions which are not a JB Fund 


4. How can this alert be resolved?

You can resolve the alert with one of the following actions:

A. Advisory Session (session alert)

Solicitation Type

Duty

Documentation (Justification / Contact Note)

Actively solicited

RM/IA to choose another instrument from the allowed universe

or

RM/IA must not proceed with the transaction as the advice is unsuitable (and the session is blocked)

No justification possible (as this is a hard block)  

Reverse solicited

RM/IA must inform the order giver of the resulting breach and propose another allowed instrument from the allowed universe

Unsolicited

RM/IA must inform the order giver of the resulting breach and propose another allowed instrument from the allowed universe (solicitation type needs to be changed to "reverse solicitation" in this case)


Important: In the event of any data issues in the system or in dedicated permitted use cases (e.g. workarounds) it is possible to overrule the alert and document it according to the defined process →Hard Block Override Procedure


B. Client Book (overnight portfolio monitoring alert)

Duty

Resolving the alert & Documentation (Resolution / Contact Note)

RM must inform the client within 5 business days


RM/IA must advice the client to sell an existing position (the alert becomes overdue after 20 business days).


5. Justification example(s)

There is no justification option.
