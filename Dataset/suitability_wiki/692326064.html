1. What is the "client feedback" functionality?

The "client feedback" functionality is an important component of the advisory session documentation process in Wealth Navigator/DiAS. Its primary purpose is to record the client's interaction with the bank, specifically their response to discussions and transactions initiated during advisory sessions. This functionality ensures that all client interactions are properly documented, providing a clear audit trail of the advisory process. The client’s feedback is also then documented in the post-trade PIR.

Examples:

  • "Client feedback" in the Wealth Navigator/DiAS session

  • "Client feedback" in the post-trade PIR

2. How "client feedback" functionality works?

The "client feedback" step is automated based on the user's actions, the nature of the transaction and the type of solicitation scenario involved based on a pre-defined logic and it will always be displayed on the Order Entry step screen, except for the transactions that have been removed (i.e. please refer to the info box at the at the foot of this page for further details).

Key default settings based on solicitation scenario:

A. Unsolicited orders

Once an unsolicited order is added to a DiAS/Wealth Navigator advisory session, the default "client feedback" is "Proceed without advice" as shown below.

B. Reverse solicited orders

Once a reverse solicited order is added to a DiAS/Wealth Navigator advisory session, the default "client feedback" is "Proceed with advice"* as shown below. In addition, a drop down menu will be available in the session so that client feedback can be changed to "Proceed against advice" if applicable.

*Please note! For the cases where an alert triggered - in the Wealth Navigator/DiAS session - is justified with "Client accepts risk", "Client confirms" or "Client insists", the default client feedback displayed in the advisory session is set to "Proceed against advice". 

C. Actively solicited orders

Once an actively solicited order is entered in the Wealth Navigator/DiAS advisory session, the default "client feedback" displayed is "Accepted" as shown below.
