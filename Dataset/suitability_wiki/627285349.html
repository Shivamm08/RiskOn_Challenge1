Increase severity level for the BMO rule: Less than 100k EUR for Structured Products

https://wiki.juliusbaer.com/spaces/fkh/pages/627285349/Increase+severity+level+for+the+BMO+rule+Less+than+100k+EUR+for+Structured+Products

The BMO rule Distribution of this Structured Product is only allowed if the minimum investment size is EUR 100'000 (or equivalent) per investor becomes stricter as the severity changes to hard block.


As part of ADESS an advisory conduct dashboard was created that identified data exception usage as the leading cause for deficiencies in DiAS alert justification controls. Despite improvements achieved through education, data exception usage still causes more than 80% of these deficiencies.

Within SURE (Suitability Remediation) the aim is to reduce the number of data exceptions by improving rules, both through tightening where the data exception should not be used and refining the rules, so no alert is triggered where the alert is not required. Further we will change the flow to provide more guidance to the RM, tackle widespread misconceptions and increase the hurdle for quick and thoughtless wrong submissions.


The RMs will no longer be able to justify using data exception the following BMO rule: "Distribution of this Structured Product is only allowed if the minimum investment size is EUR 100'000 (or equivalent) per investor" in case of active or reverse solicited cases, since the alert's severity is increased from soft block to hard block.

However, the RMs would still be able to proceed if they switch to unsolicited.
