Option 1: How to set and change a limit order

OVERVIEW OF THE STEPS

1. Proceed with a regular Session by adding the order.
2. Complete the next steps and select "Process Order"


3. Portfolio Analysis List of orders is getting opened and shows the details of the Order.
4. Now click on the pencil icon of the order 

 

5. Set the limit price to your needs and 'Validate', which will check the validity of the entered values

6. On successful validation, the user can submit the order by clicking on 'Send'
7. A confirmation message shows that the order has successfully been sent to the market.
8. Go back to Session of the Client create the Contact Note and finalize the Session
