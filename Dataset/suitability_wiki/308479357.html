Block orders for Toolbox instruments

  • There is no possibility to place block orders for different ZRs in Toolbox if one of them needs to be processed in WN.

Multiple orders in the Toolbox

  • For the same ZR, there is a possibility to enter multiple orders into Toolbox. Once entered in Toolbox (after clicking “PROPOSE”) and re-directed to WN, the advisory session can be processed for the multiple orders.
  • STEP-BY-STEP: Place the order in the Toolbox and click on “PROPOSE” in order to open the advisory session in WN. The transaction from Toolbox will be carried onto WN.

Note: The orange notification shows when an order needs to be processed via WN. In this case (and only), the standard button (“ACCEPT”) will be converted into “PROPOSE”, automatically re-directing the transaction into WN. Multiple orders can be added by repeating the below illustrated process.


Every time you click “PROPOSE”, a new WN window will open. Close each window (opened automatically)and return to Toolbox, until the last order is accumulated in WN.



DiAS Advisory session with multiple Toolbox orders

When all orders have been added to the transaction list in DiAS, the advisory session can be initiated. Tick “CLIENT PACKAGE” and go through the normal advisory session steps until Order Entry.


DiAS /Toolbox orders completion

During the Order Entry step, click on “PROCESS” to be re-directed back to Toolbox.


Inside Toolbox click “ACCEPT” to execute the order.
Note: “PROCESS ALL ORDERS” is not available for Toolbox instruments in DiAS. As described above, there is a need to process every single transaction individually.


After executing all orders, click on “CREATE CONTACT NOTE & FINISH SESSION” to complete the advisory session.

Note: One Contact Note will be issued including all order details
