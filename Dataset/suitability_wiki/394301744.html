Steps how to Add Custom Instrument:

In the 'Proposal' Screen user goes through Positions' to the option 'ADD POSITION' then selects from the Dropdown 'ADD CUSTOM INSTRUMENT'

User follows the 'Create a new custom financial instrument - step 1' dialog by selecting 'Instrument Type', 'Instrument Category', 'Risk Country' then clicks on 'Next'

User follows the 'Create a new custom financial instrument - step 2' by adding the details of the instrument like 'Industry', 'Risk Currency', 'Suitability Risk Rating',
'Name - Line 1', 'Name - Line 2' and proceed further by click on 'Next'

The Instrument is successfully created and you should copy the Identification number which is created 'Dummy Valor'. Please click 'Next' to and confirm with 'Yes' to close this tab.


Now you can select again 'Add Position' within the Proposal and enter the 'Dummy Valor' which you were seeing in the previous closed screen.

Once the details about 'Type of the Order, Units, Amount, Solicitation and Reason for advice' has been added click on 'Add'.


In order to proceed further with the Order with the custom instrument the switch to the Proposal Details Tab needs to be done. Tick the 'Status' → 'Visible in Session' checkbox which makes the proposal visible in the session.

By clicking on Advisory Session a new session will be initiated. Select the left navigation in order to see the proposal with the custom instrument which you have created.
Select and load it into the Transactions basket by hitting '+'. 

The custom instrument appears in the session and the suitability checks are run. The triggered alerts need to be handled according to the rules in place and the session can be completed.

Issuer Concentration is not automatically calculated in WeNa, as no issuer can be captured (BC CH – there is a difference to BC Asia). The issuer concentration needs to be calculated manually.
